Our match engine combines TF-IDF lexical frequency maps with LLM semantic reviews. When a candidate CV is parsed, we index core skills, years of verified experience, and academic benchmarks. These attributes are weighed dynamically against the target role requirements using structural cosine weights and vector proximity mapping.

Currently, the engine accepts standard PDF and Microsoft Word (.docx) documents. These formats ensure exact metadata retrieval, and allow the RAG parsing microservices to extract clean textual content without layout distortion.

The Big Five projection evaluates lexical indicators inside candidate text blocks to estimate traits (Openness, Conscientiousness, Extraversion, Agreeableness, Neuroticism). This lets recruiting managers assess cultural compatibility and team fit. Recruiters can also trigger the Psychometric Test wizard for candidates to verify these projections directly.

The optimizer utilizes Groq's Large Language Models (LLM) to rewrite resume achievements. It aligns bullet points to Google's X-Y-Z formula ("Accomplished [X] as measured by [Y], by doing [Z]"), inserts missing critical skill keywords relevant to the target profile, and formats the output into clean, printable markdown.
